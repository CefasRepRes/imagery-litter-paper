ICES R code.R is the R file that drives the analysis.
The file functions.R is read in by ICES_R_code.R. It contains additional bespoke functions used in the analysis. The files
stills.csv, trawls.csv, videos.csv, still_sizes.csv and AUV.csv are all data files used by ICES_R_code.R

The full trawl, MPA monitoring and AUV datasets are (or are due to be) stored in Data Archive Centres. The majority of the trawl data is publicly available and stored on the International Council for the Exploration of the Sea (ICES) Database of Trawl Surveys (DATRAS), while most of the MPA monitoring data is publicly available and stored in The UK Archive for Marine Species and Habitats Data (DASSH).

Please note, that any data not already published in the Data Archive Centres are subject to change. Please check the Data Archive Centres for the most up-to-date data.

Autosub3 was designed, operated and its instrumental data derived by members of the Marine Autonomous and Robotics Systems (MARS) team of the National Oceanography Centre (https://www.noc.ac.uk/our-work/marine-technology/ocean-vehicles).
